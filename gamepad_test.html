Press any button on your VR controller to activate it.
Make sure it's paired via Bluetooth.
📋 Instructions:
1. Go to Phone Settings → Bluetooth
2. Pair your VR controller (it should show as "Connected")
3. Open this page in Chrome or Edge
4. Press and hold any button on the controller for 2 seconds
5. Move the joystick and press buttons to see values

✅ Expected Behavior:
• Status changes to "✅ Controller Connected"
• Joystick shows axis values (-1.0 to 1.0)
• Buttons highlight when pressed

⚠️ Troubleshooting:
• Controller paired but not detected? → Restart browser
• No axes/buttons shown? → Controller might be in keyboard/mouse mode
• Still not working? → Try pairing again or check battery

🔍 Browser Support:
